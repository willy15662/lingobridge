選擇翻譯服務、語言與呈現方式。

閱讀偏好

翻譯段落中的文字，保留原頁面的閱讀順序。

反白翻譯：選取文字後按 Alt+Q，以一般翻譯顯示結果；可在 Chrome 快捷鍵設定修改。

授權後重新整理網頁。媒體翻譯不會自動啟動整頁文字翻譯。

翻譯服務

使用自己的 API Key。翻譯內容會傳送到你設定的服務；金鑰只在擴充套件內保存。

儲存時會請求已填入金鑰之 API 網址的連線權限。自訂相容服務請填完整 API 網址。

譯文樣式

Reading opens a window to another world.

閱讀，為你開啟另一個世界的窗。

網站規則

每行一個網域，例如 example.com 或 *.example.com。黑名單會覆蓋自動翻譯規則。

新增規則後，按「授權白名單網站」允許自動翻譯。也可以在網站的 Popup 中逐一授權。

用量與本機資料

此處是本機記錄，不是服務商帳單；Token 僅統計服務回報的數量。

設定備份

匯出不包含 API Key。匯入僅保留相同 API 網域的金鑰，請確認內容後按儲存。
